GLITCH

오류는 실패일까, 아니면 새로운 이미지의 시작일까? 글리치(Glitch)는 디지털 시스템의 순간적인 오류를 의도적인 시각 언어로 전환한 표현 방식이다.
Visual Error

Noise / Fragment / Repeat
01 / DEFINITION

오류가
디자인이 되는 순간

글리치는 원래 전자 장치나 디지털 시스템에서 발생하는 짧고 예기치 않은 오류를 뜻한다. 디자인에서는 화면 깨짐, 색 분리, 신호 손실, 픽셀 노이즈처럼 ‘정상적이지 않은 상태’를 일부러 드러내어 긴장감과 속도감, 불완전성을 표현한다.

A / ERROR

결함의 노출

완성된 화면 뒤에 숨겨진 디지털 구조가 오류를 통해 표면으로 드러난다.

B / ACCIDENT

우연성

통제하기 어려운 흔들림과 불규칙성이 예측 불가능한 리듬을 만든다.

C / AESTHETIC

의도된 불완전함

오류를 제거하는 대신 남겨 두고, 하나의 조형적 스타일로 적극 사용한다.

02 / HISTORY

신호의 결함에서
디지털 미학으로

글리치 미학은 텔레비전 신호 왜곡과 전자 영상 실험에서 출발해, 컴퓨터 그래픽과 인터넷 문화, 현대의 브랜딩과 인터페이스로 확장되었다.

1960s

전자 영상 실험

비디오 신호를 변형하고 전자 장치의 특성을 작품 자체의 재료로 사용하는 실험이 등장했다.

1990s

디지털 오류

컴퓨터 이미지와 압축 파일의 손상, 픽셀 깨짐이 새로운 시각 현상으로 인식되기 시작했다.

2000s

Glitch Art

데이터 손상과 소프트웨어 오류를 의도적으로 만들어 작품화하는 디지털 아트 흐름이 확산되었다.

NOW

Interface Culture

뮤직비디오, 패션, 게임, 브랜딩, 웹 인터페이스에서 역동적이고 반항적인 이미지로 활용된다.

03 / VISUAL LANGUAGE

글리치를 만드는
네 가지 시각 원리

SHIFTSHIFT

01. Channel Offset

RGB 색상 채널을 서로 다른 방향으로 미세하게 이동시켜 영상 신호가 어긋난 듯한 인상을 만든다.

SLICESLICE

02. Slice & Displacement

이미지 또는 텍스트의 일부 구간을 잘라 수평·수직으로 밀어내어 파편화된 구조를 만든다.

NOISE

03. Noise

스캔라인, 픽셀 점, 압축 노이즈 등을 겹쳐 디지털 화면의 물성과 불안정한 신호감을 강조한다.

ECHOECHOECHO

04. Repeat & Echo

같은 요소를 중첩하거나 반복해 시간 지연, 잔상, 데이터 중복처럼 보이는 효과를 만든다.
